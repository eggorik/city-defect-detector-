# ADR-0004. Склейка наблюдений через DBSCAN по расстоянию

**Статус:** принято, радиус подбираем на проверочном маршруте.

## Контекст

Машина снимает один и тот же объект на нескольких кадрах подряд. В списке он должен быть одной записью (US4).

## Варианты

1. DBSCAN по координатам кадров с метрикой haversine, отдельно для каждого класса.
2. Трекинг объектов между соседними кадрами (ByteTrack и т. п.).
3. Не склеивать.

## Решение

Вариант 1: просто, работает с отдельными фото, а не только с видео. Радиус по умолчанию 10 м, min_samples = 1. Итоговые координаты — среднее по наблюдениям, статус — худший из наблюдений, лучший кадр — с максимальной уверенностью детекции.

## Последствия

- Координаты кадра — это координаты машины, а не объекта; ошибка в несколько метров ожидаема.
- Два одинаковых объекта рядом (две опоры через 8 м) могут склеиться. Проверяем на маршруте и уменьшаем радиус при необходимости. Если кадры идут видеопотоком, можно перейти на вариант 2.
