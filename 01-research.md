## Спайк: проверка технических рисков

Пока данных от организаторов нет, проверяем подход на открытых данных: Mapillary Vistas (уличные фото с классами «manhole» и «utility pole»), наборы с люками и опорами на Roboflow Universe, свои фото с телефона.

| Риск | Кто проверяет | Как проверяем | Результат |
| ---- | ------------- | ------------- | --------- |
| Детектор не находит колодцы и опоры на уличных фото | CV-инженер | Zero-shot детекторы (YOLO-World, Grounding DINO) на 50–100 кадрах, затем базовое дообучение YOLO на открытых наборах | |
| Объём ручной разметки не укладывается в сроки | CV-инженер | Доля рамок zero-shot детектора, которые можно принять без правки | |
| В кадрах нет GPS или он неточный | Аналитик | Извлечение GPS из EXIF; сопоставление кадров с треком по времени; проверка на своих фото | |
| Интерфейс не успевает к интеграции | Разработчик интерфейса | Каркас Streamlit: загрузка кадров, карта folium, таблица на заглушках | |
