# ADR-0002. Детектор YOLO с zero-shot предразметкой

**Статус:** принято.

## Контекст

Нужно находить кабельные колодцы, опоры и другие объекты на фото с камер автомобилей. Размеченных данных пока нет. В команде есть опыт обучения YOLO.

## Варианты

1. Дообучить YOLO (ultralytics) на своей разметке.
2. Использовать только zero-shot детектор (YOLO-World, Grounding DINO) без обучения.
3. Двухэтапный детектор вроде Faster R-CNN.

## Решение

Вариант 1, а zero-shot детектор используем для предразметки: он набрасывает рамки, человек их правит. Стартовую модель обучаем на открытых наборах до выдачи данных.

## Последствия

- Плюс: быстрый инференс, знакомый инструмент, разметка быстрее в несколько раз.
- Минус: zero-shot ошибается на редких объектах — правка рамок всё равно нужна.
- Если zero-shot на данных организаторов окажется достаточно точным, сравним его с дообученной моделью на проверочной выборке и выберем по mAP@50.
