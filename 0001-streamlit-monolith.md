# ADR-0001. Монолит на Streamlit без бэкенда и базы данных

**Статус:** принято.

## Контекст

Нужен работающий прототип за время хакатона. Пользователь — один человек на демо, нагрузки нет. В команде есть опыт Streamlit.

## Варианты

1. Streamlit-приложение, которое напрямую вызывает Python-модули пайплайна.
2. FastAPI-бэкенд + отдельный фронтенд.
3. Только ноутбук Jupyter.

## Решение

Вариант 1. Он быстрее всего даёт интерфейс, а модули пайплайна не зависят от Streamlit, поэтому при необходимости их можно обернуть в API позже. Данные храним в pandas и parquet, без базы.

## Последствия

- Плюс: минимум кода и инфраструктуры.
- Минус: не масштабируется на много пользователей. Для прототипа это не важно, на защите называем это следующим шагом.
